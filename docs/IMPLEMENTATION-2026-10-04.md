# Improvements implemented — 4 October 2026

This implementation follows the [3 October review](IMPROVEMENT-PLAN-2026-10-03.md), starting at `7886b4a`. The historical research and its diagnostic assertions remain intact; acceptance now lives in product regression tests.

| Finding | Resulting behavior                                                                                                                                                                                                                                                                                                                                                    |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| N01     | Malformed query names are safely masked during request logging; a real child server keeps answering subsequent requests.                                                                                                                                                                                                                                              |
| N02     | IndexedDB opening failure reports unreadability and permits retry, rather than switching to an empty store. Ownership must be persisted before migration. BroadcastChannel is optional. Failed operations remain journaled; older fallback drafts retain both versions, outbox tombstones survive reconciliation, and notification choices use the more private copy. |
| N03     | Normal desktop close/quit captures visible composer text, awaits draft/outbox persistence and drains native settings before destroying the window. Failed or timed-out preparation offers retry, keeping the window open to copy, or explicit unsaved exit.                                                                                                           |
| N04     | Microphone replacement uses the latest mute intent. Both join entry points wait for current preference initialization; unreadable preferences keep the microphone off, with retry available.                                                                                                                                                                          |
| N05     | Each app form owns its input and submission state. A previous form's success, refusal or network failure cannot close or contaminate its replacement.                                                                                                                                                                                                                 |
| N06     | Deleted-message tombstones and superseded replay events lose button labels, values and URLs along with their other content.                                                                                                                                                                                                                                           |
| N07     | Completed schedules retain completion metadata without redundant text or attachment IDs. Schema migration cleans existing sent records.                                                                                                                                                                                                                               |
| N08     | One view can have one callback in flight. Concurrent duplicate submission receives `409 view_submitting`; validation correction and deliberate transport retry remain usable.                                                                                                                                                                                         |
| N09     | Delayed replace/delete directives become a no-op if the originating message disappeared or changed. An app may continue updating its own response through the same response URL.                                                                                                                                                                                      |
| N10     | Whole-thread retention invalidates root/reply attachment caches, including evicted history and late transfers. Unknown-owner entries are conservatively revalidated on removal.                                                                                                                                                                                       |
| N11     | Restored-workspace safety holds survive damaged name, port and time fields. Uncertain held identities remain blocked instead of being adopted for ordinary hosting.                                                                                                                                                                                                   |
| N12     | Failed connector/server cleanup retains ownership and requires successful cleanup before reopening or changing access. Cleanup waits are bounded and can be retried.                                                                                                                                                                                                  |

Schema version 37 cleans active database copies while preserving current message actions and unsent schedules. It does not erase old backups or freed disk bytes. Callback exclusion prevents simultaneous submissions, but an uncertain external transport retry can still repeat an app's business effect; apps should deduplicate using the view ID.

Browser storage intentionally refuses an alternate backend after an IndexedDB opening failure. Old unrecognized conflicting legacy values remain available until explicit replacement, rather than being silently erased or restoring stale sign-ins. Fresh browsers without IndexedDB retain localStorage support until the profile adopts IndexedDB.
