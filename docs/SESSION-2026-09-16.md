## Two bugs found by e2e, both fixed and held by tests

- Menu v1 closed on **any** scroll event, so the live timeline settling under
  an open menu detached it mid-click (`element was detached from the DOM`).
  Menus now reposition on scroll/resize and only close when the trigger is
  gone. Regression test: "stays open when something else on the page scrolls".
- The labels work made the sign-in toggle `role="tab"`, but e2e helpers still
  queried `role="button"`. Helpers now use tab roles for the toggle and
  button roles for the submit.

## Traps (all bitten, all documented)

- **Build before e2e.** `tests/e2e/web.spec.ts` runs `apps/server-cli/dist/`.
  Rebuild web + server-cli after any UI/server change or failures lie.
- **A failing test restarts the worker with fresh hooks and a fresh server.**
  `web.spec.ts` tests 1–9 share one server; after a failure, later tests see
  an empty workspace (e.g. sign-in meets a register form). Always fix the
  FIRST failure and rerun; later ones are usually cascade. Diagnosed via
  per-tick listener-PID polling plus temp `[e2e-diag]` logging (since
  reverted) — reuse that technique if it ever smells again.
- **Isolated `--grep` runs of dependent tests fail**: tests 7–9 need users
  created by tests 1–2. Run the whole file.
- **Playwright clicks scroll into view**: don't close popovers on scroll.
- Prettier gates CI (`pnpm exec prettier --check .`); run `--write` on
  touched files before committing.
